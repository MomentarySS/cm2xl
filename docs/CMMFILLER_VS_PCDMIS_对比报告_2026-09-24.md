### 3.2 ⚠ 语义等价差异（不修）

#### 3.2.1 `minus_tol`（下公差）— 4 行

PC-DMIS 原生对**单边公差**写空字符串 `''`，cm2xl 写数字 `0`。
两者的**数值语义等价**（空 cell 与 0 都让 -TOL 列不影响判定），但**格式不完全相同**。

| feat_id | PC-DMIS 原生 | cm2xl | 类型 |
|---|---|---|---|
| CC_21 | '' | 0 | 几何公差（垂直度）+0.3 单边 |
| CC_41 | '' | 0 | 几何公差（平面度）+0.4 单边 |
| CC_42 | '' | 0 | 几何公差（圆柱度）+0.5 单边 |
| CC_49 | '' | 0 | 几何公差（平面度）+0.5 单边 |

**判定**：用户 2026-09-24 拍板「语义等价，无需改」。cm2xl 模板简化的设计取舍：
单边公差 vs 双边公差靠「`+TOL` 是否配 `-TOL`」区分，不靠 -TOL cell 是否为空区分。
PC-DMIS 用空字符串明确标注「无下公差」，cm2xl 写 0 让报表阅读者看到「下公差 = 0」的实际限。
**结论**：格式瑕疵，**不修**。

#### 3.2.2 `description`（描述）— 17 行

17 行差异全部是**命名翻译**问题，**不涉及数据**：

**类别 A — 5 个位置度行**：「尺寸位置」vs「半径位置」

| CC_1 | 尺寸位置 (圆柱1) | 半径位置 (圆柱1) | cm2xl 配对逻辑把头行「尺寸位置」替换为附属行类型「半径位置」 |
| CC_9 | 尺寸位置 (圆9) | 半径位置 (圆9) | 同上 |
| CC_11 | 尺寸位置 (圆槽1) | 半径位置 (圆槽1) | 同上 |
| CC_37 | 尺寸位置 (球体1) | 半径位置 (球体1) | 同上 |

代码位置：`modules/pc_to_excel/core/_dimension.py:407-409` 的 `_resolve_dimension_record_type()`，
「半径/半角位置头行本身常无实测，报告描述用附属行类型」是**已存在的设计**。

### 3.3 ✗ 数据缺陷（必修 — P3-11.1）

#### `bonus`（BONUS 列）— 6 行

PC-DMIS 原生对**位置度 / 垂直度 / 平行度 / 倾斜度**这 4 种 GD&T 写 `BONUS=0`，
cm2xl 输出 `None`（漏填）。

| feat_id | GD&T 类型 | PC-DMIS 原生 | cm2xl |
|---|---|---|---|
| CC_38 | 位置度 (圆柱3) | **0** | **None** |
| CC_39 | 垂直度 (圆柱D) | **0** | **None** |
| CC_50 | 垂直度 (平面6) | **0** | **None** |
| CC_51 | 垂直度 (平面6) | **0** | **None** |
| CC_52 | 平行度 (平面6) | **0** | **None** |
| CC_69 | 倾斜度 (平面12) | **0** | **None** |

**根因（推断）**：
- `modules/cmm_filler/core/parse_measurements.py:_resolve_gdt_nums()` 返回 `[nominal, +TOL, -TOL, measured]` 四元组，**未读 BONUS 列**
- 导出侧 `pc_to_excel/export/pcdmis_style_report.py` 拿到四元组即按四列输出，BONUS 列永远填 None

**圆度 / 圆跳动 / 同轴度 / 轮廓度**在 PC-DMIS 原生里 BONUS 也是空，
cm2xl None = **语义等价**，无需修。

**位置度 / 垂直度 / 平行度 / 倾斜度**这 4 种类型的 PC-DMIS 原生 BONUS 写 0（**位置度允差补偿场景**），
cm2xl 漏填 —— **必修**。

详细修法见 `docs/CORE_DEFECT_PLAN.md` 的 `### P3-11.1 BONUS 列漏填` 章节（2026-09-24 登记）。

## 4. 格式差异（设计如此，不修）

| 差异 | 说明 |
|---|---|
| 元数据行少 2 行 | cm2xl 简化了 PC-DMIS 原生元数据（去掉统计基准、序列号） |
| 列数 13 → 10 | cm2xl 去掉「特征」「段」「DEVANG」3 列（PC-DMIS 原生模板的可选列） |
| cm2xl 多 1 列「轴」 | 描述旁单独成列，PC-DMIS 原生把轴放在「特征」列内 |
| -TOL 0 vs '' | cm2xl 不区分单边公差 vs 双边公差的 cell 空与非空 |
| 描述列命名翻译 | cm2xl 内部把 ASME → ISO、尺寸位置 → 半径位置（设计翻译规则） |

其它差异均为**翻译命名 / 列结构精简 / 语义等价的格式差异**，按设计不修。
