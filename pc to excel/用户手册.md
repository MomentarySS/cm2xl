# PCDMIS 按需 Excel 测量报告 — 用户手册

> 版本 1.4.5 · 适用 PC-DMIS **2022.1–2026.1**（COM 自动发现 ProgID；主测环境 2024.1）

## 功能概述

本工具解决「必须跑完整测量程序才能出 Excel 报告」的问题，支持：

1. **外部一键导出**：读取 PCDMIS 当前 PRG 已有实测数据，生成与内置 Excel 格式一致的 xlsx。
2. **PRG 命令植入**：在程序末尾插入 `PC2XL_EXPORT` 脚本命令，测量中随时「从光标执行」即可导出 CSV。
3. **出货检测表填入**：按尺寸序号对齐写入厂内出货表，只改三坐标（可配置代号）行，不顶掉其它检具行。

## v1.4.5 更新（多件连续导出）

连接方式：`PCDLRN.Application` / `PCDLRN.Application.主.次`。营销版本与内部号大致一年 +1（本机已核实 **2024.1 → `.19.1`**）。

| PC-DMIS | 常见 ProgID（约） | 连接 | 尺寸读数 | 形位公差（ISO） |
|---------|-------------------|------|----------|-----------------|
| 2022.1 | `.17.1` | ✓ 注册表发现 | ✓ Legacy | 弱：多走 `IsFcfCommand` 回退 |
| 2022.2 | `.17.2` | ✓ | ✓ | ✓ `ToleranceCommand` 主路径 |
| 2023.1 / 2023.2 | `.18.1` / `.18.2` | ✓ | ✓ | ✓ |
| 2024.1 / 2024.2 | `.19.1` / `.19.2` | ✓（主测） | ✓ | ✓ |
| 2025.1 / 2025.2 | `.20.1` / `.20.2` | ✓ 预期 | ✓ 预期 | ✓ 预期 |
| 2026.1 | `.21.1` | ✓ 预期 | ✓ 预期 | ✓ 预期 |

说明：

- 工具启动时扫描 `HKCR\PCDLRN.Application*`，并合并上表兜底列表（未安装的版本号会跳过）。

- **BONUS / MMC·LMC / 复合段** 等边角差异见下文「后续改进（待样例）」。

## 方式 A：外部一键导出

1. 启动 PCDMIS，打开含实测数据的 .PRG（测到一半也可以）。
2. 启动本工具，点击 **连接 PCDMIS**。
3. 勾选 **仅导出报告窗口数据**（默认），点击 **一键导出 Excel**。
4. 在 `reports` 或指定目录查看 xlsx。

### Excel 布局（与 PCDMIS 原生一致）

**表头（第 1–5 行）：**

| 行 | A 列 | B 列来源 |
|----|------|----------|
| 1 | PC-DMIS测量程序 | `PartProgram.Name`（如 本体1.PRG） |
| 2 | 零件名 | `PartProgram.PartName` |
| 3 | 序列号 | `SerialNumber` 或 SN / V_SN / SERNO 变量 |
| 4 | 日期 | 导出时刻（2026/7/25） |
| 5 | 时间 | 导出时刻（17:08:47） |

第 6 行为空行，**第 7 行起为数据列：**

`尺寸` · `描述` · `轴` · `NOMINAL` · `MEAS` · `+TOL` · `-TOL` · `BONUS` · `DEV` · `OUTTOL`

**示例：**

| 尺寸 | 描述 | 轴 | NOMINAL | MEAS |
|------|------|-----|---------|------|
| 基准 | 尺寸位置 (点4) | X | 0 | 0 |
| 基准 | 尺寸位置 (点4) | Y | -8.5 | -8.5 |
| FAI_17A | 尺寸位置 (圆槽1) | L | 4 | 3.995 |
| FAI_6 | 尺寸位置 (圆3) | D | 7 | 7 |
| FAI_1 | 尺寸 2D 距离 (圆3,圆槽1) | M | 14 | 14 |

### 导出范围说明

| 选项 | 含义 |
|------|------|
| 仅导出报告窗口数据（默认） | 已评价尺寸、形位公差、大小尺寸；**不含**圆/面等原始特征 |
| 仅 Mark 命令 | 与 PCDMIS 报告输出一致，只取 Mark 的尺寸命令 |
| 取消勾选「仅报告窗口」 | 导出全部可识别数据 |

若某尺寸未出现在报告中，请在 PCDMIS 中确认该命令已 **Mark**，且 Output To 含 Report。

### 命令行

```bat
python cli.py export -o reports\out.xlsx
python cli.py export --all -o reports\full.xlsx
python cli.py fill-form --form "出货.xlsx"
```

## 方式 B：PRG 内从光标执行

1. 连接 PCDMIS 后，点击 **部署 BAS 脚本**（首次）。
2. 点击 **植入/更新导出命令** — 在 PRG 末尾插入 `PC2XL_EXPORT`。
3. 在 PCDMIS 中 **Ctrl+S 保存 PRG**。
4. 光标移到 `PC2XL_EXPORT` → **文件 → 部分执行 → 从光标执行**。
5. 脚本导出 **CSV** 到 `reports\pcdmis_partial_export.csv`。

## Phase 2：出货检测表填入

适用「序号 + 规格 + 检具代号 + 多件实测列」的厂内出货表（如 `661-*-出货.xlsx`）。

> 自定义 xlsx 模板导出已在 v1.4.2 移除；一键导出固定为 PC-DMIS 列格式。厂内表格请用本节功能。

### GUI

先打开分区右上角 **「展开」**（默认收起），再操作：

1. 勾选「启用填入」，选出货表（建议先自己复制一份底稿）。
2. **尺寸前缀**：逗号分隔，默认 `FAI_,CC_,尺寸_`（可按 PRG 命名改）。
3. **CMM代号**：逗号分隔，默认 `A,CMM`（若表里三坐标用别的字母，改这里）。
4. **写入列**：`auto` 自动找下一空列（**跳过已有实测的列**），或填 `H`/`I` 指定列。
5. 勾选 **接着上次结果填入**（默认开）：第一件写完后记住输出；第二件起以上次文件为底稿，自动下一列。
6. **写入件号**（可选）：填第 5 行送检件号；留空则尝试用 PCDMIS 序列号。
7. **手工对照**（可选）：`FAI_17A=17.1; POS_A=34`，解决命名对不上序号的情况。
8. **核对规格/名义**（可选）：B 列规格与测量名义差过大时在结果中警告。
9. 点「填入出货检测表」→ **先预览**（写入列 / 匹配数 / 未匹配 / 序号冲突）→ 确认后另存。换一批时重新「选出货表」或点「清除续填」。
10. 「恢复默认」可一键还原常用前缀与 CMM 代号（保留已选表路径）。

### CLI

```bat
python cli.py fill-form --form "C:\path\出货.xlsx" --prefixes "FAI_,CC_,尺寸_" --cmm-codes "A,CMM" --target-col auto
```

输出路径勿与 `--form` 相同（会拒绝覆盖底稿）。

### 匹配规则

| PCDMIS 尺寸名 | 出货表 A 列 |
|---------------|-------------|
| `FAI_1` / `CC_1` / `尺寸_1` | `1` |
| `FAI_12-1` | `12.1` |
| 手工对照（设置里 `manual_map`） | 任意特例 |

仅当该行 **测量仪器列** 属于 CMM 代号列表时才写入；其余行完全不动。

## 尺寸读取说明（技术）

PC-DMIS 中一条报告尺寸常对应 **多条相邻 IsDimension 命令**：

| 头行（有 ID） | 附属行（无 ID） | 合并结果 |
|---------------|-----------------|----------|
| 尺寸位置 `基准` | X轴位置 / Y轴位置 / Z轴位置 | 基准，3 行 X/Y/Z |
| 尺寸位置 `FAI_17A` | 长度位置 | FAI_17A，轴 L |
| 尺寸位置 `FAI_6` | 直径位置 | FAI_6，轴 D，NOM 从附属行读取 |
| 尺寸位置 `FAI_2-1` | 锥角位置 | FAI_2-1，轴 A，评价仍为「尺寸位置」 |

工具会自动合并这些命令，过滤 `长度位置_211`、`锥角位置_251` 等系统命名 orphan 行。

## 形位公差读取说明（技术）

| 项目 | 说明 |
|------|------|
| 主路径 | `IsToleranceCommand` → `ToleranceCommand`（2022.2+ / 2024.1） |
| 兼容路径 | `IsFcfCommand` → LINE1（大小）/ LINE2（公差）/ LINE3（次要） |
| 尺寸区 | `sizeCountCombined` 循环（如 FAI 同时含大小 + 位置） |
| 位置/形位区 | **区段 × 特征** 双重循环；跳过 `- LS` 构造特征与 FCF 名称行 |
| Excel 描述 | 统一为 `ISO 几何公差命令 (特征名)`（与原生导出一致） |
| 轴字母 | 位置度倾向 `TP`；平面度/同心度等沿用 COM 轴（常为 `M`） |

**已知差异 / 待有数据时验证：**

- 带 MMC/LMC 时原生 **BONUS** 列可能仍为空或与报告窗口略有差异
- 复合公差多段（SEG=1/2）、图案位置度多特征命名（`FAI_x-1`）需对照原生 Excel
- 工具为简化 10 列（无「特征/段」宽表列），数据内容可对齐

## 常见问题

| 现象 | 处理 |
|------|------|
| COM 连接失败 | 检查工具与 PCDMIS 权限是否一致 |
| 未提取到数据 | 确认 PRG 已打开且含已测尺寸；检查 Mark |
| 出现 `X轴位置_176`、`长度位置_211` | **旧版问题**；请用 v1.1.2+ 重新导出 |
| FAI_17A / 基准 / FAI_2-1 名称不对 | 同上，需多行合并逻辑 |
| ISO 公差沉到表尾 | 用 v1.1.1+（按命令序号排序） |
| 多孔位置度只出一条 | 用 **v1.1.3+**（多特征双重循环） |
| NOMINAL 为 0 但 MEAS 有值 | v1.1.0+ 已从附属行读取名义值 |
| 弹窗「**未找到脚本文件**」 | **部署 BAS** → **植入/更新** → Ctrl+S；路径见 `%LOCALAPPDATA%\PCDMIS_ExcelExporter\scripts\` |
| 植入后 PRG 保存失败 | 命令已在内存中，手动 **Ctrl+S** 保存即可 |
| 数值差 0.001 | COM 浮点精度 vs PCDMIS 显示四舍五入，通常可接受 |

### PRG 保存失败（植入命令时）

| 原因 | 处理 |
|------|------|
| PRG 只读 / 网络盘无写权限 | 另存到本地可写目录 |
| PCDMIS 正在执行 | 停止执行后再植入 |
| COM Save 被拦截 | 手动 Ctrl+S |

### 对比验证

可用内置脚本对比工具导出与 PCDMIS 原生 Excel：

```bat
python tools\compare_excel_reports.py
```

（需先修改脚本内两个 xlsx 路径）

## 目录结构

```
pcdmis_excel_exporter/
├── main.py              入口
├── cli.py               命令行
├── connector/           COM 连接
├── core/                数据提取与报告过滤
├── export/              PC-DMIS 样式 Excel / 出货表填入
├── inject/              PRG 命令植入
├── tools/               对比诊断脚本
├── scripts/             BAS 模板
├── reports/             默认输出

```
