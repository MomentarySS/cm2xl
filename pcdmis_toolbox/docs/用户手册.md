# cm2xl 用户手册

> 版本：1.0.11 · 适用环境：Windows 64 位 · PC-DMIS 2017 R2–2026.1

---

## 1. 软件简介

**cm2xl** 是面向三坐标测量房的统一工具箱，整合了两个常用功能：

| 模块 | 用途 |
|------|------|
| **CMM 报告填充** | 对 CMM 测量报告 PDF 做 OCR 识别，自动填入 Excel 检验模板 |
| **PCDMIS 导出** | 通过 COM 接口读取 PC-DMIS 当前程序数据，导出 Excel 测量报告，或填入出货检测表 |

左侧导航可在两个模块间切换；顶栏提供「设置」和「关于」；底栏显示 PC-DMIS 连接状态与当前操作提示。

---

## 2. 运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 7 / 10 / 11（64 位） |
| PC-DMIS | 2022.1 – 2026.1（仅「PCDMIS 导出」模块需要） |
| 网络 | **无需联网**（测量房离线可用，OCR 模型已内置） |
| 权限 | 普通用户即可；若 PC-DMIS 以管理员运行，本工具也需以管理员运行 |

> 首次启动会加载 OCR 引擎，约需 10–30 秒，请耐心等待启动画面完成。

## 3. 启动与主界面

### 3.1 启动方式

- **安装版**：双击桌面或开始菜单中的 cm2xl 快捷方式。
- **开发模式**：在项目目录执行 `python main.py`（需 64 位 Python 3.12+）。

若已有实例在运行，会提示是否启动第二个实例（两个实例共用同一份配置，一般不建议）。

### 3.2 主界面布局

```
┌──────────────────────────────────────────────────────────┐
│  cm2xl  v1.0.11                    [关于] [设置]         │
├──────────┬───────────────────────────────────────────────┤
│ 📊 CMM   │                                               │
│  报告填充 │           当前模块工作区                       │
│ 📐 PCDMIS│                                               │
│  导出    │                                               │
├──────────┴───────────────────────────────────────────────┤
│ PC-DMIS: 未连接/已连接  |  当前模块  |  操作提示          │
└──────────────────────────────────────────────────────────┘
```

- 点击左侧按钮切换模块。
- 「设置」：外观、OCR 模型、日志等全局选项。
- 「关于」：版本信息、预览颜色说明、配置与日志路径。

### 3.3 数据存放位置

| 内容 | 安装版路径 | 说明 |
|------|-----------|------|
| 配置 | `%LOCALAPPDATA%\cm2xl\config\` | 各模块 settings.json |
| 日志 | `%LOCALAPPDATA%\cm2xl\logs\` | 含 crash.log、各模块日志 |
| OCR 缓存 | `%LOCALAPPDATA%\cm2xl\cache\` | 可清理，清理后识别稍慢 |
| BAS 脚本 | `%LOCALAPPDATA%\PCDMIS_ExcelExporter\scripts\` | PCDMIS 命令植入用 |

安装版**不会**把配置写在程序安装目录，避免权限问题。

## 4. CMM 报告填充

将 CMM 三坐标测量报告（PDF）中的尺寸数据 OCR 识别后，按序号填入 Excel 检验记录表。

### 4.1 典型流程（三步）

1. **选择 Excel 模板** — 贵司的检验记录表（.xlsx）。
2. **选择 PDF 文件夹** — 存放测量报告的目录（支持一次处理多个 PDF）。
3. **点击「▶ 开始处理」** — 识别并写入 Excel。

首次使用会弹出引导窗口，也可把文件/文件夹**直接拖入**对应输入框。

### 4.2 「处理」页配置说明

| 配置项 | 说明 |
|--------|------|
| Excel 模板 | 要填入的目标表格；可点「浏览」或拖入 .xlsx |
| PDF 文件夹 | 含测量报告 PDF 的目录；可拖入整个文件夹 |
| 输出文件夹 | 生成文件的保存位置，不存在会自动创建 |
| 报告版式 | 匹配不同 CMM 厂商报告格式（如默认 FAI/FAL/DIM）；切换后需重新识别 |
| 额外前缀 | 在 Profile 基础上追加尺寸编号前缀，逗号分隔 |
| OCR 裁剪 | 按百分比裁掉页眉/页脚，只识别测量区域（上/下/左/右 %） |
| 处理前预览识别结果 | 建议保持开启：先核对再写入 |

### 4.3 识别预览

开启预览后，处理会先识别所有 PDF，再弹出预览窗口：

| 颜色/标记 | 含义 |
|-----------|------|
| 普通行 | 识别置信度正常 |
| 橙色行 + ⚠ | 置信度偏低，请对照 PDF 核对实测值（不等于不合格） |
| 紫色行 + ⚡ | 多个子编号对应模板同一序号，需选择填入哪一项 |
| 红色 NG 标签 | 实测值超出公差，判定不合格 |

操作要点：

- **取消勾选** = 剔除该项，不写入 Excel。
- **实测值列** 可直接手工修改。
- 确认后点击「确认并写入」继续。

### 4.4 其他功能按钮

| 按钮 | 功能 |
|------|------|
| 导出标准模板 | 导出一份空白标准模板供参考 |
| ⚙ 模板配置 | 打开模板配置向导，设置列映射、样品列、品名/日期写入位置 |
| 📂 输出路径 | 复制输出文件夹路径到剪贴板 |
| 📃 查看日志 | 打开 CMMFiller 运行日志 |
| 🧹 清理 OCR 缓存 | 删除 OCR 渲染缓存，下次识别会稍慢 |

### 4.5 「汇总导出」页

将多个 PDF 的测量数据汇总到**一个 Excel 文件**（每个 PDF 一个 Sheet）：

1. 点「＋ 添加 PDF」或拖入多个 PDF / 文件夹。
2. 确认输出文件夹。
3. 点「▶ 生成汇总 Excel」。

### 4.6 「NG 分析」页

批量统计文件夹内各 FAI 项目的 NG 率，导出含三个 Sheet 的统计 Excel：

- NG 排行
- 详细记录
- FAI 明细

使用「处理」页相同的 PDF 文件夹、输出文件夹及版式/OCR 设置。

另提供「通用表格提取」：针对**文字型 PDF**（非扫描件），从汇总页选中的 PDF 提取表格（需 pdfplumber）。

### 4.7 「结果」页

处理完成后展示统计卡片（成功/失败/跳过/NG 等）及生成文件列表。

### 4.8 自定义报告版式（Profile）

- 内置多种报告版式，下拉选择即可。
- 点「Profile 目录」可打开用户自定义 Profile 文件夹，放入 JSON 文件后重启或刷新即可使用。
- 自定义 Profile 可配置：尺寸前缀、跳过行、OCR 裁剪比例、置信度阈值等。

### 4.9 模板配置向导

若贵司 Excel 模板列位置与标准模板不同，使用「⚙ 模板配置」：

1. 选择模板文件 →「加载模板」查看表头。
2. 配置列映射（序号、规格、上下公差、测量仪器等）。
3. 配置样品列（1#–5#）。
4. 配置品名、日期的写入单元格（如 D5、L2）。
5. 保存配置。

配置保存在 `%LOCALAPPDATA%\cm2xl\config\cmm_filler\template_config.json`。

## 5. PCDMIS 导出

从正在运行的 PC-DMIS 读取当前测量程序数据，导出 Excel 或填入出货检测表。

### 5.1 使用前准备

1. **启动 PC-DMIS**，并打开要导出的测量程序（.prg）。
2. 确认本工具与 PC-DMIS **权限一致**（都普通用户，或都管理员）。
3. 在 cm2xl 左侧切换到「PCDMIS 导出」。

### 5.2 连接 PC-DMIS

1. 点击「连接 PCDMIS」。
2. 连接成功后，状态显示为 **● 已连接**，并显示版本与当前程序名。
3. 底栏同步显示 PC-DMIS 连接状态。
4. 不用时点「断开」。

**连接失败常见原因：**

- PC-DMIS 未运行或未打开程序。
- 权限不匹配（一个管理员、一个普通用户）→ 两边统一权限后重试。
- PC-DMIS 版本不在支持范围内。

### 5.3 一键导出 Excel

主流程，生成 PC-DMIS 列格式的完整测量报告：

1. 设置「输出目录」。
2. 可选勾选：
   - **仅报告窗口数据** — 只导出报告窗口中的尺寸（不含程序里未上报告的）。
   - **仅 Mark 命令** — 只导出带 Mark 标记的命令。
3. 点击「一键导出 Excel」。

导出列包含：尺寸、描述、NOMINAL、MEAS、+TOL、−TOL、BONUS、DEV、OUTTOL 等。

> **测到一半也能出表** — 不必等全部测完，随时可导出当前已测数据。

### 5.4 PC-DMIS 工具栏一键出报告

测完后在 PC-DMIS 工具栏点一下即可出 Excel（默认仅 Mark 命令），不必先打开 cm2xl。

1. 在 cm2xl「PCDMIS导出」里点 **部署工具栏启动器**（只需一次）。
2. PC-DMIS：**视图 → 工具栏 → 自定义 → 创建项目**，选择  
   `%LOCALAPPDATA%\PCDMIS_ExcelExporter\scripts\cm2xl_toolbar_export.vbs`  
   （若对话框不认 vbs，改用同目录的 `.bat`）。
3. 从「用户自定义命令」把该项拖到工具栏，关闭自定义对话框。
4. 测量完成后点击该按钮。

cm2xl 会跳过 OCR 启动画面，打开「PCDMIS导出」并自动导出。若 cm2xl 已在运行，会唤醒现有窗口再导一次。

> 工具与 PC-DMIS 须同为普通用户或同为管理员。PC-DMIS Pro 无 BASIC，工具栏请用 vbs/bat，不要选 `.bas`。

### 5.5 出货检测表填入

适用于按序号往贵司出货检验表中续写 CMM 测量值（默认折叠，点「展开」可见）：

1. 勾选「启用填入」，选择出货检测表 Excel。
2. 配置：
   - **尺寸前缀** — 如 FAI、DIM（逗号分隔）。
   - **CMM 代号** — 表中标识 CMM 行的代号。
   - **写入列** — `auto` 自动找空列，或指定 H、I 等。
   - **接着上次结果填入** — 多件测量时自动续下一空列，不覆盖已有数据。
   - **写入件号** — 可填送检件号，空则用 PCDMIS 序列号。
   - **核对规格/名义** — 写入前校验规格是否匹配。
   - **手工对照** — 特殊尺寸的手动映射规则。
3. 点击「填入出货检测表」→ 先预览匹配 → 确认后另存新文件。

### 5.6 PRG 命令植入（边测边导出 CSV）

适合在测量过程中从 PC-DMIS 内部触发导出：

1. 先点「部署 BAS 脚本」（只需做一次）。
2. 连接 PC-DMIS 后，点「植入 / 更新导出命令」→ 保存 PRG。
3. 测量时，在 Edit 窗口将光标放在 `PC2XL_EXPORT` 命令行。
4. 菜单：**文件 → 部分执行 → 从光标执行**（或选中命令块 → 执行块）。
5. 脚本导出 CSV 到指定位置。

> - PC-DMIS **Pro** 版无 BASIC 扩展，请用外部「一键导出」。
> - 完整 xlsx 列格式请用「一键导出 Excel」，命令植入导出的是 CSV。

### 5.7 界面底栏

- 左侧：当前操作进度说明。
- 右侧：状态文字（就绪 / 已连接 / 导出中等）。

## 6. 全局设置

顶栏「设置」→ 保存后生效（部分项需重启）：

| 分组 | 选项 | 说明 |
|------|------|------|
| 外观 | 浅色 / 深色 / 系统 | 立即生效 |
| OCR 模型 | 高精度(Server) / 轻量(Mobile) | 高精度适合正式报告；轻量更快 |
| OCR 模型路径 | 自定义目录或留空用内置 | 修改后下次 OCR 时生效 |
| 日志 | DEBUG / INFO / WARNING | 排错时可调为 DEBUG |
| 清理 | 清理日志 / 清理 OCR 缓存 | 立即执行 |

「兼容性 → 导出旧版配置」：从旧版 CMMFiller / pc to excel 迁移设置时使用。

## 7. 常见问题

### Q1：启动很慢？

首次启动需加载 PaddleOCR 模型（约 10–30 秒），属正常现象。后续启动会快一些。

### Q2：提示「已有实例在运行」？

说明 cm2xl 已在后台运行。可在任务栏找到窗口，或结束进程后重新启动。不建议同时开两个实例。

### Q3：OCR 识别不准？

1. 切换「报告版式」到匹配的 Profile。
2. 调整「OCR 裁剪」，去掉页眉页脚干扰。
3. 在预览窗口手工修改实测值或剔除误识别项。
4. 在设置中确认使用「高精度(Server)」模型。

### Q4：连接 PC-DMIS 失败？

1. 确认 PC-DMIS 已打开且加载了程序。
2. 检查权限：工具栏会显示「PCDMIS:普通/管理员」与「匹配 ✓/权限?」。
3. 查看日志：`%LOCALAPPDATA%\cm2xl\logs\pc_to_excel.log`。

### Q5：导出 0 条数据？

- 确认已连接且程序中有已执行的测量。
- 若勾选了「仅报告窗口数据」，确认尺寸已加入报告。
- 若勾选了「仅 Mark 命令」，确认相关命令已 Mark。

### Q6：程序崩溃或报错？

详情写入 `%LOCALAPPDATA%\cm2xl\logs\crash.log`。请将日志发给软件维护人员。

### Q7：日志占用空间过大？

- 启动时自动裁剪（总量超约 100MB 会删最旧文件）。
- 也可在「设置 → 日志 → 清理日志文件」手动清理。
