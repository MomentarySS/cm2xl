## 三、打包交付建议

### 推荐方案：PyInstaller 目录版 + 安装包

```
用户拿到的是：
CMMFiller Setup 1.0.0.exe
  → 安装到 C:\Program Files\CMMFiller\
  → 桌面快捷方式 + 开始菜单
  → 首次运行引导
```

### 具体步骤

1. **修正 `CMMFiller.spec`**
   - GUI 模式：`console=False`（不要弹黑窗口）
   - `datas` 带上 `templates/` 下模板文件
   - 确认 `hooks/` 路径正确

2. **OCR 模型内置**
   - 打包前运行 `download_ocr_models.py`，模型打入 `models/paddleocr/`（约 17-30 MB）
   - 用户安装后完全离线可用，无需首次联网下载

3. **用 Inno Setup 做安装程序**（免费、成熟）
   - 创建桌面快捷方式
   - 写入卸载项
   - 可选：关联 `.pdf` 右键菜单「用 CMMFiller 处理」

4. **体积预期**
   - PaddlePaddle + PaddleOCR 打包后约 **400–800 MB**
   - 对工业软件可接受，但要在说明文档里写清楚

## 四、产品化功能建议（按优先级）

### P0 — 必须有（第一版发布）

| 功能 | 原因 |
|------|------|
| 版本号 + 关于对话框 | 现场出问题要知道版本 |
| 首次运行引导 | 选模板 → 选 PDF 目录 → 选输出目录 |
| 处理进度（x/50） | 现在只有 indeterminate 进度条，50 个 PDF 时用户焦虑 |
| 处理结果摘要 | 「成功 48 / 失败 2」，附失败文件名 |
| 记住上次路径 | 写入 `%LOCALAPPDATA%\CMMFiller\settings.json` |
| 一键打开日志 | 日志在 `%LOCALAPPDATA%\CMMFiller\run.log` |

### P1 — 第二版增强

| 功能 | 价值 |
|------|------|
| 拖拽 PDF/文件夹到窗口 | 质检员最爱 |
| 处理前预览 OCR 结果 | 减少填错 |
| 多模板管理 | 不同零件对应不同 xlsx |
| 批量重处理失败项 | 只重跑失败的 PDF |
| NG 项高亮/统计 | 结合 NG 分析能力 |

### P2 — 差异化

| 功能 | 场景 |
|------|------|
| 定时监控文件夹 | PDF 放入即自动处理 |
| 与 MES/QMS 对接 | 上传结果到质量系统 |
| 多机授权/配置同步 | 多台电脑统一模板 |

│  📋 日志区域                            │

- **错误要说人话**（「OCR 未识别到零件名」而非堆栈）
- **完成后给明确下一步**（「打开输出文件夹」「查看失败清单」）

## 六、现场可靠性（制造业场景）

1. **离线可用** — 模型和依赖尽量内置，不依赖现场联网
2. **Excel 被占用** — 已有 `_safe_save()`，GUI 可提示「请关闭 Excel 后重试」
3. **PDF 格式变化** — 保留 OCR 缓存图片，方便排查
4. **模板误配** — 处理前做列映射校验（「未找到规格列 C」）
5. **自动备份** — 已有 `_bak_时间戳`，可在 GUI 显示备份路径

## 七、代码结构建议（不必大改）

当前单文件 `cmm_filler_v10.py`（~40KB）还能维护，但发布前建议轻量拆分：

```
cmmfiller/
├── core/          # OCR、解析、Excel 填充
├── gui/           # 主界面
├── wizard/        # 模板向导
├── config/        # 配置读写
└── __main__.py    # 入口
```

好处：版本迭代、单元测试、打包都更清晰。不必现在就做，**第一版发布后**再拆即可。

## 九、定位建议

这不是通用 OCR 工具，而是：

> **「CMM 测量报告 → Excel 检验记录」的专用自动化工具**

卖点：
- 针对 CMM PDF 格式优化，比手工录入快 10 倍
- 支持多日期、多样品自动分组
- 模板可配置，换零件不用改代码
- 离线运行，数据不出厂

## 十、技术路线总结

| 维度 | 建议 |
|------|------|
| 技术路线 | 继续 Python + CustomTkinter + PyInstaller，不必换框架 |
| 最大投入 | 打包稳定性 + 首次体验 + 进度反馈 |
| 最大风险 | OCR 模型首次下载、向导在 exe 中失效、缓存写权限 |
| 最快路径 | 先修 4 个硬伤 → 打包测试 → Inno Setup 安装包 → 给同事试用 |

## 附录：关键路径说明

| 路径 | 用途 |
|------|------|
| `%LOCALAPPDATA%\CMMFiller\template_config.json` | 模板列映射配置 |

| `%LOCALAPPDATA%\CMMFiller\outputs\` | 打包版默认输出目录 |
| `dist\CMMFiller\CMMFiller.exe` | 打包产物 |
| `models\paddleocr\` | 内置 OCR 模型（det/rec/cls） |
| `templates\模板2.xlsx` | 内置 Excel 模板 |
