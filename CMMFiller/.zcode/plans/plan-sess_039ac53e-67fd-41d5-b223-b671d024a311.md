# 新功能：多 PDF 汇总导出（每个 PDF 一个 Sheet）

## 结论
新增「汇总导出」功能：用户挑选若干 PDF → 全部提取数据写入一个 Excel 文件，每个 PDF 一个 sheet，样式按参考图（CMM Dimensions Report 汇总风格）。已确认：坐标系/补偿两列保留但留空（源 PDF 无此数据）、独立选文件界面、加报告信息行。

## 一、核心层 `cmm_filler_v10.py` — 新增 `export_summary_workbook()`

新方法（约 100 行），签名：
```python
def export_summary_workbook(self, pdf_paths, output_folder, progress_callback=None) -> dict
```

**流程**：
1. 接收显式 PDF 路径列表（不走文件夹 glob，不套用误操作文件过滤——用户是主动挑选的）
2. 逐份 `pdf_to_image → ocr_image（有缓存）→ parse_from_text`，进度回调 `idx/total`
3. `openpyxl.Workbook()` 新建工作簿（不用模板，汇总样式独立），删默认 sheet
4. 每个 PDF 一个 sheet：
   - **sheet 名** = PDF stem，净化非法字符 `[]:*?/\`、截断 31 字符、重名加 `_2` 后缀
   - **行1**（合并 A1:J1）：`CMM Dimensions Report 汇总 — {文件名.PDF}`，加粗 14pt 居中
   - **行2**（合并 A2:J2）：`零件名: xxx    日期: xxx    序列号: xxx`（序列号取 stem）
   - **行3** 表头 10 列：`序号 | 注释 | 坐标系 | 补偿 | 理论值 | 实际值 | 误差 | 下公差 | 上公差 | 趋势`，加粗、浅灰底、细边框、居中
   - **行4+** 每个测量项一行（按 num 排序）：序号=num、注释=desc、坐标系/补偿=空、理论值/实际值/下公差/上公差=原值、误差=实测-理论（round 4 位）、趋势=超差量（dev>上公差 → dev-上公差；dev<下公差 → dev-下公差；合格留空，与参考图一致）
   - 数字格式 `0.0000`（对齐参考图 4 位小数）；**NG 行**的 实际值/误差/趋势 红色字体（复用 `ng` 字段）
   - 列宽：注释 ~40、数字列 ~12；冻结表头 `freeze_panes='A4'`；全表细边框
5. `_safe_save` 保存为 `{输出文件夹}/数据汇总_YYYYMMDD_HHMM.xlsx`（沿用锁重试+备份机制）
6. 返回 `{total_pdfs, processed_pdfs, failed_pdfs, output_file, ng_count, sheet_count}`；单份失败记日志不中断其余

## 二、GUI `cmm_filler_gui.py` — 新增「汇总导出」Tab

- Tabview 顺序变为 **处理 / 汇总导出 / 结果**（在 `tabs.add('结果')` 前插入）
- `_build_summary_tab()`：
  - **选文件卡**：「＋ 添加 PDF」按钮（`askopenfilenames` 多选）、「清空」按钮、文件计数；`CTkScrollableFrame` 文件列表（每行文件名 + ✕ 单删），`self._summary_files: list[Path]` 保序维护
  - **拖拽**：`_setup_dnd` 扩展 kind=`'summary_files'`，`_on_drop` 接受多个路径——.pdf/.PDF 文件直接加入，文件夹则把内部 PDF 全加入（复用 `_parse_drop_paths`）
  - **输出卡**：输出文件夹行，绑定共享的 `self.output_var`（与处理页同一设置，随 settings.json 记忆）
  - **「▶ 生成汇总 Excel」按钮** + 本 Tab 专属进度条
- `_summary_start()`：`self.processing` 防重入 → 校验列表非空/输出目录 → `_begin_work()`（同步禁用两个开始按钮，`_processing_done` 恢复）→ 后台线程跑 `_run_summary_export`（照抄 `_run_export` 的 try/except/root.after 模式）
- 完成后：日志+弹窗摘要、切换到「结果」页（徽章填 total/processed/failed/ng，文件列表列出汇总 xlsx + 复制路径按钮）
